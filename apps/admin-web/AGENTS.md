# XcAIPool 前端 UI 规范

- 工作台使用现有黑白双色设计。新增或修改组件时，复用 `src/style.css` 的语义色、描边、圆角、焦点和动效变量，并沿用现有 Lucide 图标。页面需同时校验深浅主题。
- 需要用户确认时，复用 `src/ConfirmDialog.tsx`；编辑、授权和详情沿用 `workbench-dialog`。应用内禁用浏览器的 `window.confirm`、`window.alert` 和 `window.prompt`。确认弹窗写清对象和影响，按钮使用具体动词，例如「移除账号」。
- 取消按钮获得默认焦点，支持 Escape 和键盘操作。取消后焦点返回触发控件。控件因成功操作离开页面时，把焦点移到就近的可用操作。
- 请求提交中应显示状态并防止重复提交。确认失败在弹窗内解释原因并允许重试，成功使用统一的 Toast。持续性问题显示在相关区域，简短操作结果才使用 Toast。
- 动效服务于进入、展开和反馈，沿用现有时长与缓动，并尊重 `prefers-reduced-motion`。布局验证桌面与窄屏，长文本应换行，主要操作应清晰可触达。
- 交付前构建并验证相关交互。涉及确认弹窗时，覆盖键盘取消、成功和失败反馈。
